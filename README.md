# MyCraft mods

The mod catalog of **MyCraft**. Every folder is one mod, inside it the mod as an encrypted `.jar` -
open it with MyCraft (title screen → **Mods** → **Catalog**), not by hand.

## Publish your mod

1. In MyCraft: **Mods → My Mods → Publish** (or **Publish** in the mod editor).
2. MyCraft opens a folder with your mod's `.jar` and this page in your browser.
3. Drag the `.jar` into the page and press **Propose changes**.
4. As soon as it is accepted, everybody sees it in the catalog.

A new version: publish again - the same folder, a bigger version number.
